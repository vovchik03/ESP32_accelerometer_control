# Схема підключення

Плата: **ESP32 DevKit (ESP32-WROOM-32)**. Усі номери пінів — це `GPIO`, а не номери
на роз'ємі. Змінюються в одному місці: [`main/board_config.h`](main/board_config.h).

```
                 ESP32 DevKit                          MPU-6050 (GY-521)
               ┌──────────────┐                        ┌───────────┐
        3V3 ───┤ 3V3          │                  VCC ──┤           │
        GND ───┤ GND          │                  GND ──┤           │
               │      GPIO 21 ├──────── SDA ─────SDA ──┤  MPU-6050 │
               │      GPIO 22 ├──────── SCL ─────SCL ──┤           │
               │              │                  AD0 ──┤ (на GND)  │
               │              │                        └───────────┘
               │              │
               │      GPIO 13 ├──────── сигнал ───────► Серво X (roll)
               │      GPIO 12 ├──────── сигнал ───────► Серво Y (pitch)
               │              │
        VIN/5V ┤              │        Серво VCC (червоний) ◄── +5 В (окреме джерело)
        GND ───┤              ├─────── Серво GND (коричневий) ── GND спільна
               └──────────────┘
```

## MPU-6050 (I2C)

| MPU-6050 | ESP32   | Примітка                                   |
|----------|---------|--------------------------------------------|
| VCC      | 3V3     | GY-521 має свій стабілізатор — можна і 5 В |
| GND      | GND     |                                            |
| SDA      | GPIO 21 | `BOARD_I2C_SDA_GPIO`                       |
| SCL      | GPIO 22 | `BOARD_I2C_SCL_GPIO`                       |
| AD0      | GND     | адреса `0x68`. На 3V3 → `0x69`             |
| INT      | —       | не використовується                        |

- Шина: `I2C_NUM_0`, 400 кГц, увімкнені внутрішні підтяжки ESP32.
  На модулі GY-521 уже є підтяжки 2.2–4.7 кОм — зовнішні не потрібні.
- Якщо AD0 підтягнутий до 3V3, зміни `BOARD_MPU6050_ADDR` на `0x69`.
- Орієнтація: вісь **X** сенсора — roll (серво X), вісь **Y** — pitch (серво Y).
  Прошивка при старті вважає, що плата лежить горизонтально (Z вгору).

## Серво SG90 / MG90S (PWM 50 Гц через LEDC)

| Провід серво         | Куди              | Примітка                          |
|----------------------|-------------------|-----------------------------------|
| Помаранчевий/жовтий  | GPIO 13 (X) / 12 (Y) | сигнал, `BOARD_SERVO_*_GPIO`   |
| Червоний             | +5 В              | **не** з піна 3V3                 |
| Коричневий/чорний    | GND               | обов'язково спільна з ESP32       |

- Імпульс 500–2500 мкс ↔ 0–180°. Старт — 90° (середина).
- Керуючий сигнал ESP32 — 3.3 В, для SG90/MG90S цього достатньо.

### Живлення серво

Два SG90 на старті споживають до ~1.5 А сумарно. Від піна `VIN`/`5V` DevKit через USB
(0.5 А) плата буде «просідати» й перезавантажуватись. Варіанти:

1. Окремий блок живлення 5 В ≥ 2 А → серво VCC; GND блока з'єднати з GND ESP32.
2. Live-USB 2 А в `VIN` + електроліт 470–1000 мкФ біля серво.

## Піни, які НЕ можна використовувати

| GPIO   | Чому                                                             |
|--------|------------------------------------------------------------------|
| 34–39  | input-only, немає вихідного драйвера → LEDC/серво не працюють    |
| 6–11   | зайняті SPI-флешем                                               |
| 16, 17 | на модулях **WROVER** зайняті PSRAM (на WROOM вільні)            |
| 0, 2, 12, 15 | strapping-піни — впливають на завантаження. GPIO 12 працює як серво-вихід, але якщо плата не стартує з підключеним серво — перенеси Y на GPIO 14 |

## Дисплей (SPI, зарезервовано)

Піни оголошені в `board_config.h`, але в прошивці поки не використовуються:
MOSI 23, SCLK 18, CS 5, DC 4, RST 2.

## Перевірка після прошивки

```
idf.py -p COMx flash monitor
```

Очікуваний лог:

```
I (xxx) mpu6050: MPU-6050 ready at 0x68
I (xxx) servo: servo on GPIO 13, LEDC channel 0
I (xxx) servo: servo on GPIO 12, LEDC channel 1
I (xxx) app: init done, entering control loop
```

| Симптом                                  | Причина                                          |
|------------------------------------------|--------------------------------------------------|
| `mpu6050: no response at 0x68`           | SDA/SCL переплутані, немає живлення, AD0 на 3V3  |
| `mpu6050: unexpected WHO_AM_I`           | на шині інший чип (MPU-9250, підробка)           |
| `servo: ledc_channel_config failed`      | вибрано input-only GPIO (34–39)                  |
| Серво стоять на 90° і не рухаються       | `IMU read failed` у логу — дивись I2C            |
| Серво крутяться «в інший бік»            | поміняти `out_min`/`out_max` у `tilt_map` в `main.c` |
| ESP перезавантажується при русі серво    | просідання живлення — окреме джерело 5 В         |
